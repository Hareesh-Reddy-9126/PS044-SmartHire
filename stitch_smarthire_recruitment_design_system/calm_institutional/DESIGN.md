## Brand & Style

This design system expresses a calm, institutional, and dependable personality tailored for employment decisions across Candidate, Recruiter, and Admin roles. It prioritizes truthfulness, informational density, and legal clarity over marketing hyperbole. The aesthetic pairs deep ink indigos with warm parchment neutrals, establishing an interface that feels archival, deliberate, and structural.

### Aesthetic Foundation
- **Movement:** Modern Institutional Minimalism. Heavy reliance on 1px hairlines, tabular density, flat surfaces, and disciplined typography.
- **Tone:** Professional, objective, calm, and rigorous. Decorative graphics and illustrative flourishes are disallowed in favor of functional typography and distinct state feedback.
- **Truthful State Presentation:** Speculative data, mock metric cards, and decorative progress meters are strictly prohibited. Unavailable capabilities are visually grounded through structured callouts and locked surfaces.

## Colors

The palette establishes an authoritative visual anchor through the Ink Indigo range, underpinned by warm neutral surfaces that reduce screen fatigue.

### Core Architecture
- **Primary (`#3E4A91`):** Applied to primary actions, interactive links, completed step indicators, and high-priority selections.
- **Secondary (`#0E7C7B`):** Reserved strictly for future or planned surfaces, forward-looking features, and recruiter tier differentiation.
- **Neutral Backgrounds:** `#FBFAF9` drives main canvas rendering, `#FFFFFF` forms standard panels, and `#F4F2F0` denotes sunken utility areas such as table headers and segmented control tracks.
- **Borders & Dividers:** Structure is established using `--c-border` (`#E3DFDB`) for resting hairline elements, and `--c-border-strong` (`#CBC5BF`) for secondary controls and highlighted bounds.

### Semantic Status Matrix
Status badge and state indicators adhere to rigid categorical assignments:
- **Success (`success-50` / `success-600`):** `OPEN`, `HIRED`, `SENT`.
- **Warning (`warning-50` / `warning-600`):** `UNDER_REVIEW`, `SCHEDULED`.
- **Danger (`danger-50` / `danger-600` / `danger-700`):** `REJECTED`, `NO_SHOW`, `FAILED`, and form validation errors.
- **Info (`info-50` / `info-600`):** `APPLIED`, `COMPLETED`.
- **Primary Ink (`c-primary-50` / `c-primary-700`):** `SHORTLISTED`.
- **Neutral Inactive (`c-surface-sunken` / `c-text-muted`):** `DRAFT`, `CLOSED`, `WITHDRAWN`, `NOT_SCHEDULED`, `PENDING`.

## Typography

Typography delivers institutional rigor via geometric stability and clear vertical cadence. 

### Font Allocation
- **User Interface (`Inter`):** Selected for high legibility, robust tabular numerical support, and consistent baseline performance across form layouts and tables.
- **Monospace Identifiers (`JetBrains Mono`):** Used strictly for machine-generated values, RFC 9457 correlation IDs, database UUIDs, API response codes, and file sizes.

### Hierarchy & Usage
- Prose blocks are constrained to a maximum width of `72ch` to safeguard comprehension.
- `overline` is paired with `text-transform: uppercase` for table column headings, status capsules, and role chips.
- Numerical data within data tables must enable tabular figures (`font-variant-numeric: tabular-nums`) to maintain column vertical alignment.

## Layout & Spacing

A strictly enforced 4px baseline rhythm drives layout spacing and visual balance.

### Grid & Form Factors
- **Desktop (≥1280px):** Fixed 240px application sidebar with a 1200px max-width content container. Standard table columns fully revealed.
- **Tablet (768px–1023px):** Sidebar converts to a 64px icon rail; grid condenses to 2 columns for job items, and secondary data columns drop out.
- **Mobile (≤640px):** Single-column layout. Data tables transform dynamically into stacked card lists. Form actions transition into a fixed, sticky bottom action bar.

### Layout Dimensions
- Table headers: `44px` height.
- Table rows: `56px` height.
- Global top bar: `56px` fixed height.
- Dialog envelopes: Constrained to `520px` (`sm`) or `640px` (`md`).

## Elevation & Depth

This design system favors crisp boundary definition over deep dimensional shadows: "Borders over shadows."

### Depth Stack
1. **Flat Base:** Flat 1px structural hairlines (`#E3DFDB`) separate zones, define inputs, and segment table records.
2. **Resting Components (`0 1px 2px rgba(28, 26, 25, 0.06)`):** Applied sparingly to discrete interactive objects such as resting job cards and active segmented pill indicators.
3. **Floating Elevators (`0 4px 12px rgba(28, 26, 25, 0.08)`):** Hover elevations and floating contextual dropdown menus.
4. **Modals & Drawers (`0 16px 40px rgba(28, 26, 25, 0.16)`):** Reserved exclusively for modal dialogs and overlay drawers, paired with a solid scrim (`rgba(28, 26, 25, 0.48)`).

### Focus Rings
Accessible interactive focus is provided by a dual-ring treatment: an inner crisp `1px` edge (`#FFFFFF`) backed by a primary ring of `2px solid #4F5BA6` and a soft `3px` glow (`rgba(79, 91, 166, 0.32)`).

## Shapes

The interface balances sharp functional discipline with slight softening on interactive elements.

- **Subtle (4px / `--r-sm`):** Callout boxes, `GapNotice`, `CopyableId`, and skeleton state containers.
- **Default (6px / `--r-md`):** Buttons, text inputs, textareas, native select dropouts, filter control wrappers, and dropzone zones.
- **Contained Surfaces (12px / `--r-lg`):** Modal dialogs and confirm prompts.
- **Pill / Circular (999px / Full):** Badges, role indicators, and sequence timeline nodes.

## Components

### Buttons
- **Primary:** Background `--c-primary-600`, text white. Hover `--c-primary-700`, active `--c-primary-800`.
- **Secondary:** Background `--c-surface`, border `1px solid --c-border-strong`, text `--c-text`. Hover `--c-surface-sunken`.
- **Danger:** Background `--danger-600`, text white. Hover `--danger-700`, active `--danger-800`.
- **Sizes:** Small (`32px`), Medium (`40px`), Large (`48px`).

### StatusBadge & RoleChip
- **StatusBadge:** `22px` height, fully rounded. Features a mandatory `6px` solid status dot paired with uppercase `overline` text. Colors match the semantic status matrix.
- **RoleChip:** `20px` height. Candidate (`--c-primary-50` / `--c-primary-70`), Recruiter (`--c-accent-50` / `--c-accent-700`), Admin (`--warning-50` / `--warning-800`).

### DataTable
- Header rows use `--c-surface-sunken` with `overline` muted labels.
- Body rows use `--c-surface` with a bottom `1px solid --c-border`.
- Responsive conversion: At viewports ≤640px, the tabular structure collapses into a stacked list of bordered cards.

### Forms & Inputs
- Inputs sit at `40px` height with a `1px solid --c-border` resting outline and a `6px` border radius.
- Labels sit `6px` above inputs using `label-md`.
- Helper and error text sit `4px` beneath using `caption`.
- Validation errors shift the border to `--danger-500` with an associated icon.

### StatusTimeline
- Displays the state machine progression. Complete steps use a filled `--c-primary-600` circle with a check icon and a connecting `--c-primary-300` solid line.
- Current active state uses a primary ring outline. Future steps are hollow with `--c-border-strong` and muted text labels.

### GapNotice & PlannedBanner
- **GapNotice:** Identifies unbacked capabilities. Uses `--c-surface-sunken` with a left `3px solid --c-text-subtle` accent and dashed `--c-border-strong` border.
- **PlannedBanner:** Flags locked roadmap items. Rendered in `--c-accent-50` with a `1px solid --c-accent-500` border and secondary teal branding.

### ErrorPanel & CopyableId
- **ErrorPanel:** Displays RFC 9457 exceptions with a `--danger-50` background, `--danger-200` border, and an integrated `CopyableId` tracking correlation IDs.
- **CopyableId:** Compact container with `--c-surface-sunken` fill, code font (`JetBrains Mono`), and a click-to-copy trigger for tracking system UUIDs.
